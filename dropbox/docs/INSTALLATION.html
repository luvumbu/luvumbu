📸 PhotoSync — Documentation technique d'installation

Application Android + serveur PHP/MySQL multi-comptes (photos & vidéos). Version app : v2.4 · Déploiement : https://luvumbu.com/dropbox

1. Architecture & prérequis

Composants

ÉlémentRôle
Serveur public_html/Site PHP : endpoints de l'app (api/), pages web (web/), librairies (lib/), stockage (uploads/).
App android/Application Android (Kotlin) — installée via l'APK.

Prérequis serveur

  • Hébergement PHP 8.0+ avec extensions pdo_mysql, gd (miniatures), mime_content_type.
  • Base MySQL / MariaDB.
  • Accès FTP (FileZilla, WinSCP…) ou gestionnaire de fichiers de l'hébergeur.
  • HTTPS recommandé (les vidéos et l'app passent par le réseau).

Prérequis pour (re)compiler l'app

  • JDK 17 (fourni par Android Studio : jbr/).
  • SDK Android (API 35) et Gradle 8.x.

2. Base de données MySQL

  1. Dans le panneau de l'hébergeur (hPanel Hostinger, cPanel…), section Bases de données MySQL, créer une base et un utilisateur.
  2. Noter précisément : nom de la base, utilisateur, mot de passe, hôte (souvent localhost).
  3. Les tables sont créées automatiquement par l'assistant et par Auth::ensureSchema() — aucun import SQL manuel nécessaire (le fichier sql/db.sql est fourni à titre de référence).

3. Téléversement des fichiers (FTP)

⚠️ Important : on envoie le contenu du dossier public_html/ (donc index.php, install.php, lib/, api/, web/, sql/, uploads/) dans le dossier dropbox/ de l'hébergement — et non le dossier public_html lui-même.

Copie de référence

La version en ligne utilise la connexion « Se connecter avec Google ». C'est la copie public_html/ (racine du projet) qui correspond — déployer depuis celle-ci.

Résultat attendu sur le serveur :

luvumbu.com/dropbox/
├── index.php
├── install.php
├── lib/      (config.php, db.config.php, Auth.php, Db.php, Api.php, Photos.php, bootstrap.php)
├── api/      (upload.php, feed.php, media.php, login.php, names.php, setup.php, …)
├── web/      (gallery.php, upload_web.php, admin.php, …)
├── sql/      (db.sql)
└── uploads/  (créé/rempli automatiquement — NE PAS écraser)

4. Assistant d'installation

  1. Ouvrir https://luvumbu.com/dropbox/install.php.
  2. Au 1er accès, un formulaire apparaît (la base n'est pas encore configurée) → saisir nom de base / utilisateur / mot de passe / hôte → Enregistrer et vérifier.
  3. L'assistant écrit lib/db.config.php (identifiants) et crée les tables.
  4. Sécurité : une fois l'installation réussie, supprimer install.php du serveur.
✅ Vérification : ouvrir https://luvumbu.com/dropbox/web/gallery.php → la page de connexion Google doit s'afficher.

6. Application Android (APK)

  1. Récupérer le dernier APK : PhotoSync-2.4.apk (ou android/app/build/outputs/apk/debug/app-debug.apk).
  2. Sur le téléphone : autoriser l'installation depuis « sources inconnues », puis ouvrir l'APK.
  3. Dans l'app : régler le domaine = luvumbu.com et le sous-dossier = dropbox, puis se connecter avec Google.
  4. Recompiler si besoin :
# JAVA_HOME = JDK 17 (jbr d'Android Studio)
gradle -p android assembleDebug
# sortie : android/app/build/outputs/apk/debug/app-debug.apk

7. Mise à jour / déploiement

Pour livrer les corrections (vidéo, origine, filtres, déconnexion…), déposer par FTP les fichiers serveur modifiés depuis public_html/ vers dropbox/ en respectant l'arborescence :

Fichier (local → serveur)Apporte
lib/Auth.phpColonne source + déconnexion fiable (efface le cookie).
api/upload.phpOrigine phone/computer/web + rangement photos/·videos/.
api/feed.phpType photo/vidéo fiable (champ video) + origine.
api/media.phpLecture vidéo en streaming (support HTTP Range).
web/gallery.phpBarre fixe, envoi direct, filtre « Afficher » par origine, couleurs.
web/upload_web.phpEnvoi tout-type + bouton « Choisir un fichier ».
La colonne source est créée automatiquement au déploiement (filet dans feed.php/upload.php + ensureSchema()) — aucune migration SQL manuelle.

8. Fichiers à NE JAMAIS écraser

  • lib/db.config.php — identifiants de la base propres au serveur en ligne (les écraser = erreur 500).
  • uploads/ — toutes les photos et vidéos stockées.

10. Dépannage

SymptômeCause / solution
Erreur 500 « Access denied for user »lib/db.config.php contient de mauvais identifiants BDD. Relancer install.php ou corriger le fichier sur le serveur (ne jamais y mettre les identifiants d'une autre machine).
Vidéo qui ne se lit pasapi/media.php sans support Range non déployé. Déposer la version corrigée. Secours dans l'app : bouton « Ouvrir en ligne ».
Photos web invisibles dans l'appLa galerie n'était pas rechargée → bouton 🔄 Actualiser (les nouveautés sont en haut, « Charger plus » ne les montre pas).
Tout s'affiche « téléphone » (bleu)api/feed.php / api/upload.php (origine) pas encore déployés.
Déconnexion qui ne déconnecte paslib/Auth.php (effacement du cookie) pas encore déployé.
