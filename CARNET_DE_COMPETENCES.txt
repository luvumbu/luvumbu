################################################################################
#  1. BOKONZI — Plateforme data (athlétisme)                                    #
#     Écosystème complet, en production : https://bokonzi.com                   #
################################################################################

CONTEXTE / OBJECTIF
  Plateforme de données autour de l'athlétisme : recherche d'athlètes,
  fiches détaillées, visualisation de statistiques et services payants.
  Un écosystème complet (web, mobile, B2B, API) alimenté par une seule
  source de données.

RÔLE
  Conception, développement et déploiement de A à Z (produit + infrastructure).

STACK TECHNIQUE
  PHP · MySQL · JavaScript · API REST (JSON) · Capacitor (Android) · CORS ·
  cache fichier · intégration de paiement en ligne · hébergement mutualisé.

COMPÉTENCES DÉMONTRÉES
  • Conception d'une API REST : 20+ endpoints JSON, cache 24 h, CORS —
    « moteur de données » unique partagé par toutes les surfaces.
  • Architecture multi-surfaces : une même API branchée sur un site web,
    une application mobile Android (Capacitor) et un espace professionnel.
  • Recherche multi-critères et génération automatique de fiches.
  • Data-visualisation (indicateurs, statistiques croisées).
  • Espace B2B : tableau de bord, effectifs, indicateurs, export CSV.
  • Intégration d'un paiement en ligne (parcours d'achat).
  • Mise en production et exploitation d'un nom de domaine dédié.

RÉSULTAT
  Écosystème en ligne et opérationnel : site public, application mobile,
  espace pro et API publique interconnectés.

#  5. ANNIVERSAIRE — Compte à rebours partagé (PWA)                              #
#     En ligne : https://luvumbu.com/anniversaire                               #
################################################################################

CONTEXTE / OBJECTIF
  Application de comptes à rebours d'anniversaires, avec espaces personnels
  protégés, partage entre utilisateurs et installation sur mobile.

RÔLE
  Développement full-stack, sécurisation et packaging PWA.

STACK TECHNIQUE
  PHP · MySQL · JavaScript · OAuth Google · PWA (manifest, service worker,
  icônes) · cURL (vérification de token).

COMPÉTENCES DÉMONTRÉES
  • Double authentification : nom + mot de passe OU compte Google.
  • Partage d'espaces entre utilisateurs (droits voir + modifier, invitations).

  • Assistant d'installation forcé : si la base est injoignable, l'app guide
    l'admin pour saisir et tester les identifiants MySQL, puis crée les tables.
  • Personnalisation par espace (thème clair/sombre, couleurs, coins, police).
  • Sécurité applicative : cookies durcis (HttpOnly / SameSite / Secure),
    protection anti-XSS, pas de fuite d'erreurs de base de données.
  • Gestion des environnements local / production (base d'URL auto-détectée).

RÉSULTAT
  Application déployée, partageable et installable, avec parcours d'installation
  autonome pour le non-technicien.
