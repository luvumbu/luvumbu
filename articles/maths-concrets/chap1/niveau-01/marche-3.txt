TITRE : Chapitre 1 · Niveau 1 · Marche 3 — Le soir : le sac se vide
---
Le soleil descend. La journée est finie.

Ilo se lève. Il siffle. Les moutons arrivent.

Le sac d'Ilo est plein de cailloux. Il le pose devant lui.


LE SOIR, C'EST L'INVERSE

Le matin, Ilo METTAIT un caillou dans le sac.

Le soir, il ENLÈVE un caillou du sac.

C'est le contraire. Tout simplement.

Un mouton rentre. Ilo enlève un caillou.

Un autre mouton rentre. Ilo enlève un caillou.

Encore un mouton. Encore un caillou enlevé.

Un mouton, un caillou. Un mouton, un caillou.


LE DERNIER MOUTON

Le dernier mouton passe la barrière.

Ilo enlève le dernier caillou.

Il regarde dans le sac.

Le sac est vide !


ILO EST CONTENT

Le sac est vide. Ça veut dire que tout va bien.

Ilo ferme la barrière. Il rentre chez lui. Il va dormir tranquille.

Tous ses moutons sont rentrés. Il en est sûr.


LE MATIN ET LE SOIR

Regarde bien les deux moments. C'est très important.

Le matin : le mouton sort → le caillou entre dans le sac.
Le soir : le mouton rentre → le caillou sort du sac.

Le sac se remplit le matin. Le sac se vide le soir.

Le sac fait le contraire des moutons ! Quand les moutons sont dehors, les cailloux sont dedans.


À TOI DE JOUER

Reprends ton bol de la marche 2, avec les cailloux dedans.

Reprends tes 4 objets.

Maintenant fais le soir : remets un objet à sa place, et enlève un caillou du bol. Un objet, un caillou. Un objet, un caillou.

Continue jusqu'à ce que tous tes objets soient rangés.

Regarde ton bol.

Il est vide ? Bravo. Tu as fait exactement ce qu'Ilo fait tous les soirs de sa vie.
