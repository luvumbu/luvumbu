1. 🧭 Présentation

CV Luvumbu est une application PHP/MySQL pour créer, mettre en forme, partager et suivre des CV. Elle propose un éditeur visuel (WYSIWYG) avec plusieurs modèles, un rendu imprimable/PDF, des liens de partage publics avec QR code, et un suivi de candidatures.

  • Back-end : PHP (PDO/MySQL), sessions, protection CSRF.
  • Front-end éditeur : moteur de rendu partagé assets/js/cv-builder.js.
  • API : REST authentifiée par clé API (api/cv.php).

3. 🎨 Éditeur de CV

L'éditeur (cv_builder.php) s'appuie sur le moteur cv-builder.js. Options principales :

  • Photo : import, taille, forme (cercle, arrondi, carré, portrait, hexagone).
  • Modèles : dc2scale (Tableautier), moderne, etc. Le bandeau latéral descend automatiquement jusqu'en bas de la page.
  • Couleurs : principale + secondaire, palettes prêtes, et overrides avancés (texte, fond, bordures, badges).
  • Coordonnées dynamiques : bouton + pour ajouter une info (📍 lieu, 📞 téléphone, 🌐 site web…), ✕ pour retirer.
  • Sections : Expérience, Formation, Compétences, Logiciels, Habilitations, Langues, Loisirs — ajout/retrait d'éléments.
  • Mise en page : « tenir sur une page », disposition libre (canvas), taille du texte.
  • Aperçu en direct : visible/masqué (masqué = formulaire plein écran).

4. 🗑️ Corbeille

Supprimer un CV le déplace dans la corbeille (suppression douce, colonne deleted_at). Depuis la corbeille, on peut restaurer un CV ou le supprimer définitivement.

5. 🔗 Partage public + QR code

Chaque CV peut recevoir un jeton de partage (share_token). Une fois le partage activé :

  • un lien public cv_public.php?token=… permet à n'importe qui de voir le CV sans compte ;
  • un QR code pointant vers ce lien est affiché ;
  • le partage est désactivable à tout moment (le lien cesse alors de fonctionner).
La page publique est en noindex (non référencée par les moteurs de recherche).

6. 💼 Suivi des candidatures

Sur le tableau de bord : pour chaque candidature, on enregistre l'entreprise, la date d'envoi, le CV envoyé, le statut (en attente / positive / négative) et une éventuelle relance.

Un bouton « + Ajouter une information » permet d'attacher des infos supplémentaires libres (libellé + valeur : poste, salaire, contact, lien…), stockées en JSON (colonne extra_json) et affichées sous forme de puces.

7. ❓ Aide & tutoriel

  • Tutoriel interactif (éditeur) : bouton 🎓 Tutoriel → visite guidée pas à pas de toutes les options (surbrillance + bulle).
  • Aide contextuelle (Mes CV) : pastilles ⓘ partout, et un Mode aide qui affiche toutes les explications d'un coup.

9. 🔌 API REST (api/cv.php)

Authentification par en-tête X-API-Key (ou Authorization: Bearer).

MéthodeDescription
GET /api/cv.phpListe les CV (scope cv:read).
GET ?id=N&profile=1Détail d'un CV + profil riche.
GET ?whoami=1Renvoie l'utilisateur et les permissions de la clé.
POST /api/cv.phpCrée un CV (champs texte et/ou profile riche).
PUT /api/cv.phpMet à jour un CV ; { "share": true } active le partage et renvoie share_url.
DELETE ?id=N[&force=1]Met à la corbeille, ou supprime définitivement avec force=1.

Permissions (scopes)

cv:read, cv:write, cv:delete, profile:read, profile:write.

10. 🗄️ Modèle de données

Table cvs

id, user_id, full_name, title, email, phone, summary, skills, experience, education, profile_json (profil riche), deleted_at (corbeille), share_token (partage public), created_at, updated_at.

Table applications

id, user_id, cv_id, company, sent_at, status, followup, followup_date, notes, extra_json (infos supplémentaires), created_at, updated_at.

Table api_keys

id, user_id, label, scopes, key_prefix, key_hash (SHA-256), created_at, last_used_at, revoked_at.
